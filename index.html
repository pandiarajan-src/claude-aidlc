Knowledge check

Build time fell, but delivery did not. What should the team measure next?

Measure time spent waiting for clarification, review, tests, and deployment. Pilot a play for the largest queue and monitor escaped defects alongside lead time.

Three Claude sessions edit different files. Does a Git worktree protect your credentials?

No. A worktree separates checkouts; process permissions and sandboxing determine what files, credentials, and network resources a process can reach.

A new acceptance test fails after Build. Should Claude edit the test until it passes?

Not by default. Compare the test to the agreed criterion. Fix the implementation if the criterion is right; return to Design for human review if the criterion itself was wrong.
